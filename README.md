# 🗺️ Maps repo

A collection of scripts for producing geospatial visualisations. This repository includes:

- Scripts for generating thematic and experimental maps   
- Outputs and figures  

The goal is to build a flexible, well-documented space for experimenting with
geospatial data and cartographic design.
